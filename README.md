# handify
Repository for the Handify music controller, done for data-vis class.

Heyo! If you want to use my little controller make sure to download all the files as a folder, as the links to certain files could break.
As well some functions utilised may not work in your browser of choice due to safety concerns with audio. Chrome has been tested and works.

Little fun thing, if you want to use your own stems for this simply delete my sound files and add your own! Just make sure to rename them as tone 1-3.
